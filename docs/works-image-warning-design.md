# Works の画像警告：設計メモ

対話で合意し、実装した設計。実装は2026-10-30に依頼された。

## 画像ごとに警告を設定する

画像警告（Spoiler Warning）は、ネタバレや刺激の強い表現などに用いる。作品のギャラリー画像ごとに設定でき、警告文も個別に指定できる。本文中の画像や動画には適用しない。同じ画像を本文にも載せた場合、本文側には警告が付かない。

警告中は画像全体に強いブラーと暗い半透明の面を重ね、中央に警告文と「画像を表示」ボタンを置く。色や大まかな構図が多少残ることは許容し、細部を判別できない見た目を目指す。

## メッセージは任意入力とし、未入力なら既定文を使う

警告の有無とメッセージの入力は分ける。メッセージがなくても警告を設定できる。

中央には次の順に表示する。

- 固定の見出し「画像に関する注意」。
- 画像ごとの説明文。未入力なら「内容を確認してから表示してください。」。
- 「画像を表示」ボタン。

カスタムメッセージは装飾やリンクを含まない文章とする。

長さは40文字程度を目安とし、厳密な文字数制限は設けない。メッセージは省略せず、画面幅に応じて折り返して全文を表示する。詳しい説明は作品本文に置く。

frontmatter の `images` に任意の `warning` を指定する。`warning` を省略した画像には警告が付かない。`warning: {}` で既定文、`warning.message` でカスタムメッセージを使う。空欄や空白だけのメッセージは既定文に置き換える。

```yaml
images:
  - image: ./cover.png
    alt: 表紙のイラスト
  - image: ./ending.png
    alt: 結末の場面
    warning:
      message: 作品の結末を含みます。
  - image: ./detail.png
    alt: 刺激の強い表現を含む場面
    warning: {}
```

## 表示ボタンで、その画像だけを表示する

- 「画像を表示」ボタンを押したときだけ、その画像の警告を解除する。
- 警告中もスワイプ、矢印、サムネイル選択で別画像へ移動できる。これらの操作では警告を解除しない。
- 解除状態は画像ごとに、そのページを開いている間だけ保持する。別画像へ移動して戻っても、解除済みの画像は表示したままとする。
- 再読み込みや再訪問では警告に戻す。
- 表示後には「隠す」ボタンを設ける。

表示・非表示は即座に切り替え、ブラーが徐々に薄くなる演出は付けない。再び隠すときも即座に覆う。キーボード操作では、切り替え後の対応するボタンへフォーカスを引き継ぐ。

サムネイルはメイン画像の解除状態と連動する。警告中はブラー、暗い面、アイコンで示し、警告文と表示ボタンは置かない。

## 警告は中央、再び隠す操作は右上に置く

警告中は中央に、警告を示すアイコン、固定の見出し、説明文、「画像を表示」ボタンを縦に並べる。既存の色、文字、ボタンのスタイルを使い、警告専用の赤色は使わない。

解除後の「隠す」ボタンは画像枠の右上に常時表示する。背景を付けて読みやすくし、スマートフォンでも押せる大きさにする。680px未満ではアイコンだけを表示し、680px以上ではアイコンと「隠す」の文字を並べる。読み上げ名はどちらも「隠す」とする。前後の矢印は左右中央に残す。

## カードでも隠し、OGP の画像指定は外す

一覧、トップページ、関連記事などのカードでは、代表画像が警告対象なら内容を隠す。カード上では警告を解除せず、カードを選ぶと作品詳細へ移動する。

カードの画像部分も、ブラー、暗い面、アイコンで警告を示す。警告文と表示ボタンは省く。

Works 詳細の OGP 画像指定は、警告の有無によらず外す。代替となる汎用 OGP 画像の整備は別作業とする。

これは既存の `docs/works-detail-design.md` にあった「代表画像を OGP に利用する」という合意を変更するものである。

## 読み上げでも、解除するまでは画像の内容を伝えない

警告中は元の画像説明を読み上げ対象から外し、警告文と操作案内を伝える。解除後に元の画像説明を読めるようにする。サムネイルとカードでも、警告があることを読み上げで伝える。

## JavaScript が動かなくても画像を隠す

読み込み直後から画像を隠し、操作できるようになる前に元画像が一瞬見えることも避ける。

JavaScript が動作しない場合は警告を維持する。表示ボタンの代わりに「表示するにはJavaScriptを有効にしてください」と案内する。

## 別作業

汎用 OGP 画像の整備は別作業。本文画像と動画への画像警告の追加は、今回の対象外とする。
